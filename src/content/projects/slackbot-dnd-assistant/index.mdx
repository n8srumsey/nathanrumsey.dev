annotations:
    - term: "MCP (Model Context Protocol)"
      detail: "An open protocol for exposing tools and data to LLMs over a standard transport. Here the MCP server is the sole owner of character state; the agent connects as a client and dispatches the model's tool calls to it over HTTP/SSE."
      style: tech
    - term: "hexagonal architecture"
      detail: "A pattern that isolates domain logic from I/O behind ports (interfaces) and adapters (implementations). Domain code depends only on Protocols, so Postgres, the test stubs, and the tool layer are all interchangeable adapters against the same core."
      style: tech
    - term: "cascade engine"
      detail: "The subsystem that applies the downstream rules consequences of a character choice automatically. Selecting a class or feat grants every proficiency, spell, and resource it implies; each granted entity records its source so the grant can be cleanly revoked if the choice changes."
      style: tech
    - term: "computed-view pipeline"
      detail: "A derivation layer that computes all character statistics (ability modifiers, saves, spell slots, derived HP) from stored identity and state rather than persisting them. Stored data stays canonical; nothing derived is ever written back, so the two can never drift."
